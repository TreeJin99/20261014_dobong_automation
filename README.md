**도봉여성새로일하기센터 · AI 기반 디지털 마케터 양성과정 · 2026.10.14 실습**

키워드 하나로 조사 보고서를 받아 보고, 기술(skill)이 어떤 구조로 움직이는지 직접 열어 봅니다.

## 오늘 만드는 것

| | 무엇 | 어디에 |
|---|---|---|
| 1 | 내 사업 한 장 | `작업파일/내사업.md` |
| 2 | 키워드 보고서 (손님 질문 · 위에 보이는 곳 · 내 제목 · 이번 주 할 일) | `작업파일/키워드보고서.md` |
| 3 | (선택) 내 반복 일 표 + 자동화 후보 1위 | `작업파일/반복일.md` |

지난 시간에 만든 `my-project` 폴더(내 사이트)는 그대로 두세요. 오늘은 새 폴더에서 합니다.

<br>

## 시작하기

**준비물** · ChatGPT 앱(Codex) · Node.js (10/12 에 설치한 것. 없으면 자동완성만 빠지고 보고서는 나와요)

**1. 받기**
1. 이 페이지 위 초록색 **Code** → **Download ZIP**
2. 압축을 풀면 `20261014_dobong_automation-main` 폴더가 생깁니다
3. 폴더 이름을 `my-work` 로 바꿉니다

**2. 열기**
1. ChatGPT 앱 → 왼쪽 위 **Codex**
2. 입력창 위 **프로젝트 선택** → `my-work` (옆의 「이 컴퓨터」는 그대로)
3. 「이 프로젝트를 신뢰할까요?」가 나오면 **신뢰**

**3. 보내기**

```
$start 로 처음부터 도와주세요
```

허락 창이 뜨면 **허용** 을 누릅니다.

<br>

## 보낼 문장과 생기는 것

| 단계 | 코덱스에 보내는 것 | 생기는 것 |
|---|---|---|
| 시작 | `$start 로 처음부터 도와주세요` | 질문 넷(하는 일 또는 하고 싶은 일 · 동네 · 손님 · 채널) → `내사업.md` + 키워드 후보 셋 |
| 키워드 보고서 | `$keyword 창동 꽃집` (키워드만 내 것으로) | `키워드보고서.md` · `키워드보고서.docx` (1~2분) |
| 반복 일 (선택) | `$routine 으로 내 반복 일을 찾아 주세요` | 반복 일 표 · 자동화 후보 1위 |

## 기술은 이렇게 생겼어요

```
.agents/skills/start/
├── SKILL.md                     매뉴얼 (입력 · 출력 · 순서 · 하지 말 것)
├── agents/openai.yaml           앱 화면 설정
├── references/questions.md      질문 넷과 번호 보기 (읽는 부록)
└── assets/business-template.md  내 사업 한 장 틀 (틀 부록)

.agents/skills/keyword/
├── SKILL.md                     매뉴얼 (맨 위 name · description = 이름표)
├── agents/openai.yaml           앱 화면에 보이는 이름 · 소개 · 기본 문장
├── references/platforms.md      플랫폼별 조사 방법 (필요할 때 읽는 부록)
├── scripts/suggest.mjs          네이버 · 구글 · 유튜브 자동완성 받아 오기 (실행하는 부록)
├── scripts/to_docx.mjs          보고서를 워드 파일로 (실행하는 부록)
└── assets/report-template.md    보고서 틀 (보고서가 매번 같은 모양인 이유)
```

`.agents` 는 숨김 폴더예요. 맥은 Finder 에서 ⌘ ⇧ . , 윈도는 탐색기 「보기 › 숨긴 항목」으로 보여요.
