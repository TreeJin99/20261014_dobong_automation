# 마케팅 일, AI 에게 맡겨 보기

**도봉여성새로일하기센터 · AI 기반 디지털 마케터 양성과정 · 2026.10.14 실습**

코딩을 몰라도 코덱스(Codex)에게 말로 시켜서<br>
내 사업의 반복 일을 찾고, AI 에게 맡겨 보고, 다음 주에 만들 「내 매뉴얼」을 준비합니다.

</div>

<br>

## 오늘 만드는 것

| | 무엇 | 어디에 |
|---|---|---|
| 1 | 내 사업 한 장 | `작업파일/내사업.md` |
| 2 | 내 반복 일 표 + 자동화 후보 1위 | `작업파일/반복일.md` |
| 3 | AI 가 만든 이번 주 콘텐츠 초안 | `작업파일/` |
| 4 | 다음 주에 기술로 만들 내 매뉴얼 | `작업파일/내매뉴얼.md` |

지난 시간에 만든 `my-project` 폴더(내 사이트)는 그대로 두세요. 오늘은 새 폴더에서 합니다.

<br>

## 시작하기

**준비물** · ChatGPT 앱(Codex) · 구글 계정

**1. 받기**
1. 이 페이지 위 초록색 **Code** → **Download ZIP**
2. 압축을 풀면 `20261014_dobong_automation-main` 폴더가 생깁니다
3. 폴더 이름을 `my-work` 로 바꿉니다

**2. 열기**
1. ChatGPT 앱 → 왼쪽 위 **Codex**
2. 입력창 위 **프로젝트 선택** → `my-work` (옆의 「이 컴퓨터」는 그대로)
3. 「이 프로젝트를 신뢰할까요?」가 나오면 **신뢰**

**3. 보내기**

```
$start 로 처음부터 도와주세요
```

허락 창이 뜨면 **허용** 을 누릅니다.

<br>

## 보낼 문장과 생기는 것

| 단계 | 코덱스에 보내는 것 | 생기는 것 |
|---|---|---|
| 시작 | `$start 로 처음부터 도와주세요` | 질문 셋 (번호나 한 줄로 답하기) → `내사업.md` |
| 반복 일 | `$routine 으로 내 반복 일을 찾아 주세요` | 반복 일 표 · 자동화 후보 1위 · 해 볼 문장 |
| 맡겨 보기 | 코덱스가 준 문장 그대로 (괄호 안만 내 것으로) | 글 초안 |
| 매뉴얼 | `방금 한 일을 다음 주에 내 기술로 만들 수 있게, 순서 다섯 줄과 하지 말 것 두 줄로 작업파일/내매뉴얼.md 에 정리해 주세요.` | `내매뉴얼.md` |
