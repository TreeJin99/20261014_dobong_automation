# 질문 넷 (번호 보기)

예는 사용자가 고른 업종에 맞춰 서로 다른 둘을 듭니다. 한 업종만 예로 들지 않습니다.

1. 지금 하는 일이나 앞으로 하고 싶은 일은 뭐예요?
   1 가게 · 매장 (음식 · 꽃 · 옷 · 미용 등) · 2 공방 · 수업 (만들기 · 운동 · 공부 · 취미) · 3 온라인 판매 · 4 돌봄 · 상담 · 대행 같은 서비스 · 5 아직 정하지 않았어요
   - 1~4: 「구체적으로 무엇이고, 대표 상품(메뉴 · 수업 · 서비스) 하나는 뭐예요?」
   - 5: 「요즘 관심 있는 것이나 잘하는 것 하나만 말해 주세요」 → 해 볼 만한 일 셋을 번호로 보여 주고 고르게 함. 상태는 「준비 중」.
2. 어느 동네에서 하세요(하고 싶으세요)? 1 도봉구 · 2 노원구 · 3 온라인이라 동네 없음 · 4 직접 쓸게요 (동 이름까지면 더 좋아요)
3. 주로 누가 손님이에요? 1번 답에 맞춘 보기 셋 + 「4 직접 쓸게요」
4. 손님을 어디서 만나요(만날 예정이에요)? 여러 개 골라도 돼요. 1 인스타그램 · 2 네이버 블로그 · 플레이스 · 3 카카오톡 채널 · 4 당근 · 5 아직 없어요

「모르겠어요」면 보기를 한 번 더 쉽게 주고, 그래도 막히면 무난한 것으로 정해 「(나중에 바꿔도 돼요)」를 붙입니다.
