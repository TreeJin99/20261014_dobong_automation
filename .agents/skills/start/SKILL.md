# 내 사업 한 장

다른 기술(keyword 등)이 일을 시작하기 전에 읽는 「내 사업 한 장」을 만든다. 상대는 코딩을 모르는 40~50대이고, 아직 사업을 시작하지 않았을 수도 있다.

## 결과물
- `작업파일/내사업.md`: `assets/business-template.md` 의 칸 그대로
- 끝에 키워드 후보 셋(동네 + 하는 일 · 대표 상품 · 손님이 칠 법한 고민)과 코드 상자 하나 `$keyword (후보 1)`

## 묻는 법
- `references/questions.md` 의 네 가지(하는 일 + 대표 상품 · 동네 · 손님 · 채널)를 한 번에 하나씩, 번호 보기로 묻는다. 앞 답에 이미 있으면 건너뛴다.
- 예는 사용자 업종에 맞춰 든다. 한 업종만 예로 들지 않는다.
- `작업파일/내사업.md` 가 이미 있으면 「1 이어서 고치기 · 2 처음부터 다시」를 먼저 묻고, 2 면 원래 파일 이름에 `_지난판_월일` 을 붙여 둔다.

## 지킬 것
- 사용자가 말하지 않은 것(가게 이름 · 가격 · 손님 불편)은 짐작해 채우지 않는다. 모르는 칸은 「(나중에 채워요)」.
- `AGENTS.md` 는 고치지 않는다.
