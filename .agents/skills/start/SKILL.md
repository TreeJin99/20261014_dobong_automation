# 내 사업 한 장 (start)

- 입력: 사용자의 짧은 답 (번호나 한 줄)
- 출력: `작업파일/내사업.md` 한 장 + 다음에 보낼 문장 하나

## 순서
1. `작업파일/내사업.md` 가 이미 있으면 「1 이어서 고치기 · 2 처음부터 다시」를 묻습니다. 2 면 원래 파일 이름을 `내사업_지난판_월일.md` 로 바꿔 둡니다.
2. `references/questions.md` 의 질문 넷을 한 번에 하나씩 묻습니다. 앞 답에 이미 들어 있는 것은 건너뜁니다.
3. `assets/business-template.md` 의 틀대로 `작업파일/내사업.md` 를 쓰고 그대로 보여 줍니다.
4. 키워드 후보 셋을 번호로 보여 줍니다: 동네 + 하는 일 · 대표 상품 · 손님이 칠 법한 고민. 끝에 코드 상자 하나 `$keyword (후보 1)` 과 「다른 후보로 하려면 키워드만 바꾸면 돼요」.

## 하지 말 것
- 사용자가 말하지 않은 것(가게 이름 · 가격 · 손님 불편)을 짐작해 채우지 않습니다. 모르는 칸은 「(나중에 채워요)」.
- `AGENTS.md` 는 고치지 않습니다.
