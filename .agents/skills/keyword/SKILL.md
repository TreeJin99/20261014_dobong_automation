# 키워드 보고서 (keyword)

키워드가 없으면 「조사할 키워드 하나를 보내 주세요. 동네 + 하는 일이나 대표 상품이면 좋아요 (예: 방학동 반찬가게 · 김장 김치 예약)」라고 한 번만 묻습니다.

## 순서
1. `작업파일/내사업.md` 가 있으면 읽어 하는 일 · 대표 상품 · 동네 · 손님 · 채널을 확인합니다.
2. `references/platforms.md` 를 읽고 그대로 조사합니다.
   - 자동완성: `node .agents/skills/keyword/scripts/suggest.mjs "키워드"` 를 실행합니다. 실행이 안 되면(Node 없음 · 인터넷 막힘) 「자동완성은 못 가져왔어요」라고 적고 웹 검색만으로 합니다.
   - 검색 결과: 네이버 · 구글을 키워드와 비슷한 말 두세 개로 검색하고, 위에 나온 글 · 가게를 열어 봅니다.
3. 고르기: 자동완성에서 내 사업 · 손님과 관계있는 말 5개, 검색 결과에서 손님 질문 5개(손님 말투로), 위에 보이는 곳 3곳.
4. `assets/report-template.md` 의 틀을 그대로 따라 채웁니다. 칸 이름과 순서를 바꾸지 않고 중괄호 부분만 채웁니다.
5. `작업파일/키워드보고서.md` 에 저장하고(있으면 덮어씀) 같은 내용을 화면에도 보여 줍니다.

## 하지 말 것
- 검색량 · 순위 · 가격 · 후기처럼 확인하지 못한 숫자는 쓰지 않습니다. 검색량은 「직접 확인할 곳」으로 안내합니다.
- 열어서 확인하지 못한 주소, 자동완성에 없던 말을 「함께 찾는 말」로 쓰지 않습니다. 못 채운 칸은 「못 찾았어요」.
- 「한눈에」와 「이번 주 할 일」은 표에 적은 내용에서만 끌어냅니다.
- 말투는 쉬운 존댓말 「~해요」.
