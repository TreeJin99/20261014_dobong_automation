# 플랫폼별 조사 방법

키워드 하나를 아래 순서로 봅니다. 코덱스가 직접 할 수 있는 것과, 사람이 직접 봐야 하는 것을 나눕니다.

## 코덱스가 직접 하는 것

| 무엇을 | 어떻게 | 알 수 있는 것 |
|---|---|---|
| 네이버 · 구글 · 유튜브 자동완성 | `node .agents/skills/keyword/scripts/suggest.mjs "키워드"` | 사람들이 이 말 뒤에 실제로 붙여 치는 말 (「함께 찾는 말」의 근거) |
| 네이버 검색 결과 | 웹 검색: 「키워드」, 「키워드 + 동네」, 「키워드 + 후기 · 가격 · 추천」 | 위에 보이는 블로그 · 플레이스 · 쇼핑. 손님 질문은 블로그 제목 · 본문 소제목 · 자주 묻는 질문에서 |
| 구글 검색 결과 | 웹 검색 (같은 말) | 가게 홈페이지 · 지도 · 커뮤니티 글 |
| 검색 흐름 · 트렌드 (구글) | `node .agents/skills/keyword/scripts/trends.mjs "말1" "말2" "말3"` | 최근 12개월 달별 관심도 · 가장 많이 찾은 달 · 최근 3달 변화 · 말끼리 비교 · 같이 찾는 말 · 급상승 말 |
| 동네 가게 | 웹 검색: 「동네 + 업종」, 다이닝코드 · 당근 동네업체 · 네이버 지도 결과 | 가까운 경쟁 가게와 그 가게가 내세우는 말 |

자동완성 고르는 법
- 동네 이름만 넣은 결과에는 구청 · 날씨처럼 상관없는 말이 섞입니다. 내 사업 · 손님과 관계있는 말만 고릅니다.
- 같은 말이 두 플랫폼 이상에서 나오면 더 믿을 만합니다. 표에 플랫폼을 같이 적습니다.
- 자동완성은 순서만 있고 검색 횟수는 없습니다. 「많이 찾는다」고 단정하지 않습니다.

트렌드에 넣을 말 고르는 법
- 동네 이름이 붙은 말(쌍문동 꽃집)은 구글 검색이 너무 적어 0 이 나옵니다. 동네를 뺀 넓은 말 2~3개를 넣습니다: 하는 일(꽃집) · 대표 상품(꽃바구니) · 손님 고민(꽃 배달). 
- 값은 검색 횟수가 아니라 상대 관심도(가장 높았던 때 = 100). 「얼마나 많이」가 아니라 「언제 많이 · 늘고 있나 · 어느 말이 더」를 봅니다.
- 한국은 네이버 검색이 더 많아 네이버 흐름과 다를 수 있다고 보고서에 한 줄 적습니다.
- 구글이 잠시 막으면(429) 1분 뒤 한 번만 다시 하고, 그래도 안 되면 「트렌드는 못 가져왔어요」.

## 사람이 직접 봐야 하는 것 (보고서 「직접 확인할 곳」에 적어 줌)

| 도구 | 주소 | 무엇을 | 왜 사람이 |
|---|---|---|---|
| 네이버 데이터랩 검색어트렌드 | https://datalab.naver.com | 네이버에서의 흐름 (나이 · 성별로 나눠 보기) | 로그인 필요. 구글 트렌드와 비교해 보기 |
| 네이버 검색광고 키워드 도구 | https://searchad.naver.com | 한 달 검색 수 · 연관 키워드 | 광고 계정(무료) 필요 |
| 구글 트렌드 | https://trends.google.co.kr | 계절에 따른 흐름 (김장 · 명절 등) | 그래프 화면 |
| 인스타그램 검색 · 해시태그 | 인스타 앱 검색창 | 사진 속 손님 반응 · 해시태그 게시물 | 로그인 필요 |
| 당근 동네 검색 | 당근 앱 검색창 | 우리 동네 사람들의 글 · 동네업체 소식 | 앱 안에서만 |
